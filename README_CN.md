ApiLens 是一款桌面/移动/Web API 工具，可将 REST、WebSocket 和 GraphQL 连接到一个工作流中。

## 主要功能
- **多客户端**: 支持 REST / WebSocket / GraphQL 客户端。
- **工作流编辑器**: 使用节点连接复杂的 API 场景并实现自动化。
- **工作组系统**: 单独隔离和管理项目。
- **OpenAPI 导入**: 按标签过滤并选择性导入端点。
- **团队协作**: 通过导出/导入 JSON 分享工作组。
- **平台**: 支持桌面端 (macOS, Windows, Linux)、移动端 (Android, iOS/iPad) 和 Web 端。
- **主题**: 高级亮色 / 暗色主题。

## 快速开始
1. **启动 ApiLens**: 打开应用程序。
2. **创建工作组**: 点击侧边栏中的 `+` 按钮创建新组。
3. **导入 OpenAPI**: 右键点击组 -> `Import Swagger` 以加载规范。
4. **运行请求**: 从列表中选择一个请求，然后点击 `Send`。
5. **创建工作流**: 点击 `+ Workflow` 连接多个请求。
