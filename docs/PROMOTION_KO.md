# 🚀 ApiLens: API 오케스트레이션의 미래를 그리다

![ApiLens Workflow Mockup](../assets/images/apilens_workflow_mockup.png)

## 🎨 연결을 넘어선 예술, 시각적 워크플로우

현대적인 API 개발은 단순한 요청과 응답 그 이상입니다. **ApiLens**는 파편화된 테스트 스크립트와 복잡한 코드를 직관적인 시각적 캔버스로 변환합니다.

### 🌟 왜 ApiLens 워크플로우인가요?

*   **코드 없는 자동화**: 복잡한 `bash`나 `python` 스크립트 없이도 노드 연결만으로 강력한 자동화 시나리오를 구축할 수 있습니다.
*   **멀티 프로토콜 조화**: REST, WebSocket, GraphQL을 하나의 흐름 속에 매끄럽게 엮어내세요.
*   **살아있는 디버깅**: 데이터가 흐르는 과정을 실시간으로 지켜보세요. 성공은 **초록색**, 실패는 **빨간색**으로 즉각 반응합니다.
*   **한눈에 보는 인사이트**: 메인 대시보드를 통해 API 상태, 응답 시간, 트래픽 추이를 실시간으로 모니터링하세요.
*   **Load Hub 성능 관제**: 같은 워크플로우를 여러 원격 에이전트에서 실행하고, RPS, 오류율, latency percentile, 에이전트 상태를 한 화면에서 확인하세요.

---

### 4️⃣ 실제 활용 시나리오: 인증 & 데이터 동기화
*   **Step 1**: `Auth API` 노드로 로그인 요청.
*   **Step 2**: 응답에서 받은 `Token`을 전역 변수로 저장.
*   **Step 3**: `Condition` 노드로 토큰 유효성 확인.
*   **Step 4**: 유효할 경우 `WebSocket` 노드를 통해 실시간 데이터 스트림 연결.

## 🛠 주요 워크플로우 기능

### 1️⃣ 노드 기반 비주얼 에디터
마우스 드래그 한 번으로 API 요청, 조건 분기, 데이터 변환 노드를 연결하세요. 논리적 흐름이 한눈에 들어오는 프리미엄 글래스모피즘 인터페이스를 경험할 수 있습니다.

### 2️⃣ 실시간 시각적 피드백
워크플로우가 실행될 때, 활성 상태인 노드는 **파란색 글로우** 효과와 함께 빛납니다. 어디서 병목이 발생하는지, 어느 조건에서 실패하는지 즉시 파악할 수 있습니다.

### 3️⃣ 지능형 데이터 맵핑
이전 노드의 응답 값을 다음 노드의 입력값으로 사용하는 과정이 그 어느 때보다 간단해집니다. JSON 경로를 시각적으로 탐색하고 맵핑하세요.

### 4️⃣ 프리미엄 메인 대시보드
단순한 도구를 넘어 시스템의 관제 센터가 됩니다. 실시간 트래픽 차트와 핵심 성능 지표(KPI)를 통해 API 에코시스템의 건강 상태를 한눈에 파악할 수 있습니다.

### 5️⃣ Load Hub 분산 성능 테스트
LoadRunner처럼 여러 원격 머신에서 워크플로우 기반 부하를 실행하고, Load Hub에서 실행 상태와 성능 지표를 실시간으로 취합합니다. 원격 에이전트 업그레이드도 drain, health check, rollback 흐름으로 안전하게 관리할 수 있습니다.

## 🚀 4단계로 시작하는 워크플로우 혁신

1.  **가져오기**: OpenAPI(Swagger) 명세를 가져와 필요한 엔드포인트를 노드로 변환합니다.
2.  **연결하기**: 시작 노드부터 끝 노드까지 실행 순서와 조건을 정의합니다.
3.  **실행하기**: 'Run' 버튼을 누르고 시스템이 시각적으로 살아 움직이는 것을 지켜보세요.
4.  **확장하기**: Load Hub에서 같은 워크플로우를 여러 원격 에이전트로 분산 실행하고 report를 내보냅니다.
