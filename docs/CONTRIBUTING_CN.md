# ApiLens 贡献指南

感谢您有兴趣为 ApiLens 做出贡献！

## 如何贡献
1. **报告错误**: 如果您发现错误，请开启一个 Issue。
2. **提交功能建议**: 如果您有改进建议，请开启一个 Issue 讨论。
3. **提交代码**: 
   - Fork 本仓库。
   - 创建您的功能分支 (`git checkout -b feature/AmazingFeature`)。
   - 提交您的更改 (`git commit -m 'Add some AmazingFeature'`)。
   - 推送到分支 (`git push origin feature/AmazingFeature`)。
   - 开启一个 Pull Request。

## 代码风格
请遵循 Flutter 官方的代码风格指南。
