ApiLens는 REST, WebSocket, GraphQL을 하나의 워크플로우로 연결할 수 있는 데스크톱/웹 기반 API 도구입니다.

## 주요 기능
- **멀티 클라이언트**: REST / WebSocket / GraphQL 클라이언트 지원.
- **워크플로우 에디터**: 복잡한 API 시나리오를 노드로 연결하고 자동화.
- **실시간 시각적 디버깅**: 실행 경로 하이라이트(Green/Red) 및 노드 펄스 애니메이션.
- **커맨드 팔레트**: (Cmd+K) 모든 워크플로우, 요청, 설정을 즉시 검색하고 제어.
- **워크플로우 템플릿**: 실무 시나리오(인증, CRUD 등) 라이브러리 내장.
- **워크그룹 시스템**: 프로젝트 단위로 데이터를 격리하고 관리.
- **OpenAPI 가져오기**: 태그 필터링 및 선택적 가져오기 기능 지원.
- **팀 협업**: 워크그룹 파일 내보내기/가져오기로 팀 공유 가능.
- **디자인**: 프리미엄 글래스모피즘 UI, 부드러운 애니메이션 및 다크 모드.
- **플랫폼**: 데스크톱(macOS, Windows, Linux), 모바일(Android, iOS/iPad) 및 웹 지원.

## 빠른 시작
1. **ApiLens 실행**: 애플리케이션을 실행합니다.
2. **워크그룹 생성**: 사이드바에서 `+` 버튼을 눌러 새 그룹을 만듭니다.
3. **OpenAPI 가져오기**: 그룹 우클릭 -> `Import Swagger`로 API 명세를 불러옵니다.
4. **요청 실행**: 목록에서 요청을 선택하고 `Send` 버튼을 누릅니다.
5. **워크플로우 생성**: `+ Workflow`를 눌러 여러 요청을 연결하여 실행합니다.
