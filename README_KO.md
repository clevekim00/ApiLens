## 🎯 프로젝트 목적

현대 소프트웨어 개발 환경에서 개발자들은 종종 파편화된 도구들을 번갈아 사용해야 합니다. REST를 위한 Postman, 자동화를 위한 커스텀 스크립트, 그리고 WebSocket이나 GraphQL을 위한 별도의 클라이언트들까지. **ApiLens**는 이러한 모든 도구들을 하나의 응집력 있는 경험으로 통합하기 위해 탄생했습니다.

우리의 목표는 **단순한 API 테스트와 복잡한 워크플로우 자동화 사이의 간극을 메우는 것**입니다. 실시간 피드백을 제공하는 노드 기반 시각적 에디터를 통해 ApiLens는 다음과 같은 가치를 제공합니다:
- **프로토콜 통합**: REST, WebSocket, GraphQL을 한 곳에서 관리합니다.
- **상용구 코드 제거**: 깨지기 쉬운 bash/python 테스트 스크립트를 견고한 시각적 로직으로 대체합니다.
- **가시성 확보**: 실시간 시각적 디버깅을 통해 데이터가 시스템을 어떻게 흐르는지 정확히 파악합니다.
- **개발 가속화**: 전문가용 커맨드 팔레트와 템플릿을 사용하여 그 어느 때보다 빠르게 작업합니다.

## ✨ 핵심 기능

### 🚀 진보된 오케스트레이션
- **시각적 워크플로우 에디터**: 노드 기반 인터페이스를 사용하여 복잡한 시퀀스(예: 인증 -> 토큰 획득 -> 웹소켓 연결)를 설계합니다.
- **실시간 시각적 디버깅**: 워크플로우 실행 과정을 실시간으로 지켜보세요. 성공한 경로는 **초록색**, 실패는 **빨간색**으로 변하며, 활성 노드는 **파란색** 글로우 효과와 함께 점멸합니다.
- **워크플로우 템플릿**: "인증 흐름", "CRUD 동기화", "GraphQL 탐색기" 등 미리 구축된 시나리오 라이브러리를 제공합니다.

### 📊 실시간 대시보드 및 분석
- **중앙 관제 센터**: 앱 실행 시 가장 먼저 만나는 프리미엄 대시보드입니다. 전체 API 에코시스템의 상태를 한눈에 파악하세요.
- **성능 메트릭 시각화**: API 헬스체크, 평균 응답 시간, 요청 성공률 및 에러율을 실시간 통계 카드로 제공합니다.
- **트래픽 트렌드**: 지난 24시간 동안의 트래픽 변화를 세련된 차트로 시각화하여 병목 지점을 즉시 발견할 수 있습니다.

### 🛠 전문 개발자 도구
- **멀티 프로토콜 지원**: REST, WebSocket(서브프로토콜 지원), GraphQL(변수 및 인트로스펙션 지원)을 위한 풀기능 클라이언트를 제공합니다.
- **커맨드 팔레트 (Cmd+K)**: 수천 개의 요청과 워크플로우를 즉시 검색합니다. 키보드를 떠나지 않고 테마나 설정을 전환하세요.
- **OpenAPI / Swagger 가져오기**: 클릭 한 번으로 전체 API 명세를 가져올 수 있는 현대적인 필터링 시스템을 갖추고 있습니다.

### 💎 프리미엄 사용자 경험
- **글래스모피즘 UI**: Flutter로 구축된 화려하고 현대적인 인터페이스는 부드러운 60FPS 애니메이션과 정교한 다크 모드를 특징으로 합니다.
- **워크그룹 시스템**: 목록이 아닌 프로젝트 단위로 작업을 구성하세요. 환경과 공유 데이터를 격리하여 관리할 수 있습니다.
- **크로스 플랫폼**: macOS, Windows, Linux 및 웹 어디서나 실행됩니다.
- **견고한 UI 테스트**: 핵심 스크린(대시보드, 요청, 임포트)에 대한 자동화된 위젯 테스트로 UI 안정성을 보장합니다.

## 📖 사용 방법

### 1. 대시보드로 현황 파악하기
ApiLens를 실행하면 가장 먼저 **대시보드** 탭이 나타납니다.
- 실시간 API 헬스체크 상태와 응답 성능을 확인하세요.
- 최근 실행된 API들의 성능 지표를 통해 현재 시스템 상태를 진단할 수 있습니다.

### 2. 워크그룹으로 조직화하기
ApiLens는 **워크그룹**을 사용하여 프로젝트를 격리합니다.
- 사이드바의 **+** 아이콘을 클릭하여 첫 번째 프로젝트를 만드세요.
- **가져오기(Import)** 기능을 사용하여 기존 OpenAPI (Swagger) JSON/YAML 파일을 불러올 수 있습니다.

### 2. 첫 번째 요청 작성하기
- 상단 탭에서 프로토콜(REST/WS/GQL)을 선택합니다.
- URL과 파라미터를 입력합니다. ApiLens는 동적으로 해석되는 **템플릿 변수** `{{ 변수명 }}`을 지원합니다.
- **전송(Send)**을 클릭하여 포맷팅된 응답, 헤더 및 실행 시간을 확인합니다.

### 3. 시각적 워크플로우 설계하기
- **워크플로우 탭**으로 이동합니다.
- 팔레트에서 노드를 드래그하여 캔버스에 배치합니다.
- 포트를 연결하여 로직 흐름을 정의합니다 (예: 로그인 노드의 `success` 출력을 조회 노드의 `input`에 연결).
- **실행(Run)**을 클릭하여 시각적 디버깅 과정을 확인합니다.

### 4. 커맨드 팔레트로 효율성 극대화하기
- 언제 어디서든 **Cmd + K** (또는 **Ctrl + K**)를 누르세요.
- 특정 요청, 워크플로우 또는 앱 명령어를 입력하여 검색합니다.
- 방향키와 **Enter**를 사용하여 즉시 이동하세요.

## 🛠 기술 스택
- **프레임워크**: 고성능 멀티 플랫폼 UI를 위한 [Flutter](https://flutter.dev).
- **상태 관리**: 견고하고 반응적인 데이터 흐름을 위한 [Riverpod](https://riverpod.dev).
- **로컬 저장소**: 빠르고 암호화된 로컬 데이터를 위한 [Hive](https://pub.dev/packages/hive) 및 [Isar](https://isar.dev).
- **네트워킹**: 고급 프로토콜 처리를 위한 커스텀 인터셉터가 포함된 [Dio](https://pub.dev/packages/dio).
